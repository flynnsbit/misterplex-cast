# x264

The on-card AirPlay helper `linux/gcast/ffmpeg` links [x264](https://code.videolan.org/videolan/x264), which is **GPL-2.0-or-later**.

`COPYING` in this directory is the GNU GPL version 2 text. The "or later" grant is x264's, not a change to that file.

Configure and source pins: `packaging/licenses/gcast-ffmpeg/NOTICE` and `SOURCE.SHA256SUMS`.
